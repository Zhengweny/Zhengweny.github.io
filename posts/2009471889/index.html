1、Dockerfile语法详解

Dockerfile 是来告诉Docker 如何组装一个镜像的。

⭐ Dockerfile 文件的基本结构 （一定要知道怎么制作镜像!）

# 以下title都得是大写的

FROM：基于哪个已有的镜像构建新镜像

WORKDIR：容器内部的工作目录 （例：WORKDIR /app）

COPY：将当前目录下的内容复制到容器内部的目录（例：COPY Centos-vault-8.5.2111.repo /etc/yum.repos.d/ # 将本地的repo源（最好和dockerfile放于同一目录）移动至容器内的yum源目录

ADD：将当前目录下的压缩包解压之后再啊拷贝至容器目录

RUN：运行命令

CMD/ENTRYPOINT:相当于开机自启动后需要运行什么命令，当容器运行时，会自动执行这条命令

（例：CMD [“nginx”, “-g”, “daemon off;”] #官网的启动命令）

EXPOSE:声明容器服务的监听端口

2、Dockerfile实战演练

⭐构建镜像命令

# -t 是指定名称

docker build -t 镜像名:版本 -f dockerfile .

例：docker build -t mynginx:v1 -f dockerfile .

1）创建一个dockerfile文件

# 每个dockerfile最好都创建一个目录去维护，方便我们一眼就知道这是什么服务的，例如以下打算制作nginx镜像，则目录直接叫nginx

[root@localhost ~]# mkdir nginx

[root@localhost ~]# cd nginx/

#查看当前基础镜像

[root@localhost ~]# vim dockerfile 

FROM rockylinux:8.9     

LABEL maintainer=”zhengwenyi”

EXPOSE 80

RUN yum install wget -y

COPY jdk-8u45-linux-x64.rpm /usr/local/

ADD apache-tomcat-8.0.26.tar.gz /usr/local/

RUN cd /usr/local && yum install -y jdk-8u45-linux-x64.rpm

ENTRYPOINT /usr/local/tomcat8/bin/startup.sh && tail -F /usr/local/tomcat8/logs/catalina.out

1、把Go代码基于dockerfile做成镜像（环境用的是centos）

# 模拟开发写go代码，这一步是开发做的

yum install go -y

[root@131_72 ~]# mkdir test

[root@131_72 ~]# cd test/

[root@131_72 test]# cat main.go

package main

import (

“net/http”

“github.com/gin-gonic/gin”

)

func statusOKHandler(c *gin.Context) {

c.JSON(http.StatusOK, gin.H{“status”: “success~welcome to study”}) // 对照下面输出

}

func versionHandler(c *gin.Context) {

c.JSON(http.StatusOK, gin.H{“version”: “v1.1版本”})

}

func main() {

router := gin.New()

router.Use(gin.Recovery())

router.GET(“/“, statusOKHandler) // 当访问为/时输出上面的”success~welcome to study”

router.GET(“/version”, versionHandler) //当访问为/version时，输出”v1.1版本”

router.Run(“:8080”)

}

# 开发写完代码会初始化

[root@131_72 test]# go mod init test

# 设置代理

[root@131_72 test]# go env -w GOPROXY=https://goproxy.cn,direct

# 构建源码

[root@131_72 test]# CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o k8s-demo main.go

#创建个python存放目录

# 开发把python编译包给你，运维你传一下

[root@131_72 python]# tar zxvf hello-python.tar.gz

# 进到这个目录下写dockerfile，主程序main.py在当前目录下

[root@131_72 app]# /root/python/hello-python/app

# requirements.txt存放python需要安装的包

[root@131_72 app]# cat dockerfile

FROM python:3.7

RUN mkdir /app

WORKDIR /app

ADD . /app/

RUN /usr/local/bin/python -m pip install –upgrade pip

RUN pip install -r requirements.txt

EXPOSE 5000

CMD [“python”,”/app/main.py”]

# 加载基础镜像
